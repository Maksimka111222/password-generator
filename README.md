# Password Generator

Simple CLI tool for generating secure passwords.

## Usage

macOS / Linux:

```bash
python3 -m src.cli --length 20
```

Windows:

```bash
py -m src.cli --length 20
```

## Tests

```bash
python3 -m unittest discover
```
